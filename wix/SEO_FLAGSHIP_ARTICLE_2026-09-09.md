## Core Behavioral Bridge thesis

**Knowledge is only one layer of SAT performance.**

A capable student can lose points because the delivery system breaks:
- task initiation
- attention drift
- working-memory overload
- inefficient strategy selection
- hyperfocus on one difficult item
- rushed end-of-module decisions
- answer changing without evidence
- weak error-review transfer

The article should distinguish:

**CONTENT GAP → STRATEGY GAP → EXECUTION GAP → PERFORMANCE SIGNAL**

Then show how Behavioral Bridge repairs the gap with:

**CLASSIFY → ACTIVATE → PREDICT → PROVE**

and an EF support layer:

**CAPTURE → PLAN → PRIORITIZE → START → SUSTAIN → MONITOR → FINISH**

## Proposed article architecture

### 1. Quick answer: Can students with ADHD do well on the Digital SAT?
Answer directly in the first screen. Avoid medical claims or guarantees. Explain that the useful question is not intelligence but which part of the performance system is failing.

### 2. The hidden problem: knowing the answer is not the same as delivering it
Introduce the knowledge-vs-execution distinction with a concrete student example.

### 3. Four common SAT friction points for students with ADHD / EF difficulty
A. Starting practice consistently
B. Attention and working-memory overload inside a question
C. Hyperfocus / time sink on one difficult question
D. Rushing, impulsive switching, or unsupported answer changes

For each:
- observable behavior
- what it is often mistaken for
- the actual decision/system repair

### 4. A Digital SAT decision system that reduces cognitive load
Teach:
**Classify → Activate → Predict → Prove**

Explain why repeatable decision routes reduce the number of choices a student must make under pressure.

### 5. Accuracy before speed
Connect to the existing Accuracy Before Speed article. Explain that speed should emerge from a reliable route rather than from trying to read/solve faster indiscriminately.

### 6. Build SAT study blocks around diagnosis, not volume
Recommended structure:
- identify one recurring error pattern
- teach/activate one method
- short targeted set
- explain the miss
- micro-redo / delayed redo
- timed transfer later

Avoid universal minute counts presented as medical prescriptions. Offer ranges/examples as adjustable structures.

### 7. The hyperfocus escape rule
Use the Digital SAT's Mark for Review behavior as part of a deliberate move-on/revisit system. Emphasize preserving the module rather than winning one question at any cost.

### 8. Use Bluebook and official practice deliberately
- full diagnostic before prescribing the plan
- use official practice to identify patterns
- review every miss and meaningful guess
- practice the actual digital environment

### 9. Accommodations: what families should know
Keep this section factual and clearly separate **test-prep strategy** from **College Board accommodation eligibility/approval**.

Official-source points to cover:
- accommodations must be approved through College Board SSD
- students should work with their school SSD coordinator/counselor or SSD directly as appropriate
- approval can take up to seven weeks, so start early
- approved accommodations can include extended time, extra/extended breaks, breaks as needed, text-to-speech, screen-reader/assistive-technology options, etc., depending on the student's approval
- approved accommodations are applied in Bluebook; students should practice with their actual approved setup
- accommodations cannot simply be added on test day
- current Fall 2026 administration details should be sourced directly from College Board at publication time

Never imply Behavioral Bridge determines eligibility or secures accommodations.

### 10. Parent role: architect, not proctor
Use the established Behavioral Bridge parent principle.

Good parent support:
- protect the scheduled block
- help make commitments visible
- ask for the next action
- review the system, not every score
- fade reminders as the student's system becomes reliable

### 11. SAT tutoring, EF coaching, or both?
